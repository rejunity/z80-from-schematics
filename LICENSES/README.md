# License texts

The root [`LICENSE`](../LICENSE) defines the component scope.

- `MIT.txt`: standard MIT license with Renaldas Zioma's copyright notice.
- `CERN-OHL-W-2.0.txt`: unmodified CERN hardware license text.
- `GPL-2.0-only.txt`, `GPL-3.0-only.txt`, `LGPL-3.0-only.txt`: standard GNU
  license texts for bundled third-party material. An upstream “or later”
  grant remains “or later”; these filenames do not narrow it.
- `third-party/`: copies of particular upstream grants and notices, with
  their original copyright holders preserved.

The standard texts were obtained from the SPDX License List data:
https://github.com/spdx/license-list-data/tree/main/text

Adding a license text to this directory does not apply it to every file in
the repository. See [`THIRD_PARTY_NOTICES.md`](../THIRD_PARTY_NOTICES.md) for
the mapping and unresolved provenance items.
